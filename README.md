# התיק שלי — a personal stock dashboard

A private family project: a Hebrew, right-to-left dashboard so an 80-year-old can follow his
own portfolio and read a few stock ideas each day.

**No personal data lives in this repository.** Holdings are parsed from a bank export inside
the browser and stored in IndexedDB on that machine only. Nothing is uploaded, committed or
transmitted. This repo contains code, a public list of Tel Aviv securities, and a generic
list of stock ideas.

Not investment advice.
